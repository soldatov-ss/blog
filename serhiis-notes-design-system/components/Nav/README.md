# Nav
Marquee-style top bar: links left, italic wordmark centred, actions right, closed by a hairline over a gilt rule.

**Consumer provides:** the site name, 3–4 links with `aria-current="page"` on the active one, search, theme toggle and Subscribe.

- Three-column grid; the wordmark is Cormorant italic 30px `ink` — it is the logo.
- Links: Jost 12px uppercase, `body`; active is `accent` with a 1px underline.
- Bottom edge: `border` hairline plus a 1px `gold` rule beneath it.
- Icon buttons are 36px circles with a `border` hairline and an `aria-label`.
- Under 640px the links collapse into a menu; wordmark and Subscribe stay.
- The theme toggle names the theme it switches to: "Clair" (day) and "Obscur" (night).
