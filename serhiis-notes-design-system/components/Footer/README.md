# Footer
Closing curtain: every page ends on `night` under a single gilt rule.

**Consumer provides:** a one-line description, up to three link columns of 3–5 links, and the copyright line.

- `night` ground, 1px `gold` top rule. Wordmark in Cormorant italic `on-night`; column heads `label` in `gold`; links `on-night-muted`, `on-night` on hover.
- Grid 2fr + three 1fr inside `page-max`; two columns under 640px.
- Always include RSS. No newsletter form here — that is the spotlight's job.
