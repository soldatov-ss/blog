# ArticleHeader
Centred title page for every post: ornamented eyebrow, title, italic dek, and a byline framed by gilt rules.

**Consumer provides:** title (one optional `<em>` word), one-sentence dek, topic, date, reading time, author initials or photo.

- Title in `title` (Cormorant 60px, `ink`), centred, `text-wrap: balance`; 42px under 640px.
- The `<em>` word turns italic `accent` — the one flourish per page.
- Dek in `lead` (Newsreader italic 22px, `body`), max `measure`.
- Byline sits between two 1px `gold` rules; avatar is a `blush` disc with `ink` initials.
- `space-64` before the prose.
