# Subscribe
Newsletter sign-up staged as a spotlight: a dark `night` panel lit by a soft `blush` glow from one corner — the page's single clair-obscur moment.

**Consumer provides:** heading (one `<em>` phrase allowed), a one-line promise, the form action, success and error text.

- Ground `night`, with a `blush` glow top-right and a faint `lagoon` glow bottom-right; text `on-night` / `on-night-muted`. Keep the text column left, away from the light.
- Input: `surface`, `border-strong`, `radius-sm`; focus adds the `focus` outline and `shadow-inset`.
- One spotlight per page: the end of an article or the bottom of the home page.
- Success replaces the form with one sentence; errors are a sentence below the input, not colour alone.
