# Tag
Topic chip for filtering and labelling posts, plus the ornamented eyebrow used above titles.

**Consumer provides:** the topic name (rendered uppercase), its link, and `--active` for the current filter.

- `sn-tag`: `label` style, `ink` text, 1px `border-strong` outline, `radius-pill`. Hover and active turn `accent`; active adds `accent-wash`.
- `sn-eyebrow`: `label` in `accent`, flanked by two small `gold` ✦ ornaments. Use `sn-eyebrow--plain` to drop them in tight spots.
- One eyebrow per card or section. Max three tags per post.
