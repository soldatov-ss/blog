# Nav

A floating `surface-card` pill with `shadow-patch`, max 1080px wide, 24px from the top. Not a full-width bar.

- **Consumer provides:** the wordmark (site name in the display face, one word in italic `gold`), 3–5 links, one primary Subscribe button.
- The current section gets `aria-current="page"`: `rose` text over a short running-stitch underline.
- On phones collapse links into a ghost "Menu" button; keep the pill.
