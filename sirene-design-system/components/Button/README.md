# Button

Pill-shaped actions; the primary one is the only rose fill on a page.

- **Markup:** `<a|button class="sr-btn sr-btn--primary|--outline|--ghost">Label</a>`, optional trailing 14px arrow SVG using `currentColor`.
- **Primary** (`rose` fill, `on-rose` text, a dashed inner stitch 5px inside): one per view — "Read the essay", "Subscribe".
- **Outline** (`rose` 1.5px border): secondary navigation — "All posts", "Next part".
- **Ghost**: tertiary text actions in the nav and footer.
- Do: keep labels to 1–3 words, sentence case. Don't: square corners, a second filled colour, icons without text.
