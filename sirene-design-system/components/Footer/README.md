# Footer

The page ends like a rug: a kilim band (`surface-deep` with `rose` stripes and `thread` diamonds), the footer on `surface-deep`, and a fringe of `thread` hanging off the bottom.

- **Consumer provides:** wordmark, one-line tagline, 3–5 links.
- Text: `on-deep` for links and the mark, `on-deep-muted` for the tagline and copyright.
- Full-bleed; inner content max 1080px.
